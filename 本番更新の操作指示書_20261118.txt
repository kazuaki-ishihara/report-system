1. 今回の版で変わること（利用者への案内用）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  【増えたもの】全員
  - 提出のお知らせ: 締め日の 3 日前から、まだ出していない人の画面の上に知らせが出る。
    前の月の締め日を過ぎてまだ出していないときも出る（メールは送りません。画面の中だけです）
  - コメント・返信を、書いた人が直せる（本文の下の「直す」。直すと「（日時 に直しました）」と出る）
  - 報告の案件に「案件なし（社内待機・研修など）」を選べる
  - 文字の字体を読みやすい BIZ UDゴシックにそろえた（Windows の PC。字体の無い端末は、これまでどおりの字体）。予備のコードに「コピー」のボタン
  【増えたもの】課長・確認者
  - 提出状況の画面に「未提出の人に提出を促す」。押すと、まだ出していない人の画面の上に知らせが出る（同じ人に 1 日 1 回まで）
  - 臨時の調査の編集の画面に「回答する人の画面で見る」（課長。公開前に、答える人にどう見えるかを確かめられる）
  【増えたもの】よくある質問のチャット
  - 続けて入れた質問を、ひとつの会話として扱う。「解決した」「解決しない」のあと、次の手（関係がありそうな質問など）を出す
  - 通信が切れた・時間がかかりすぎたときに「もう一度送る」を出す（入れ直さずに送り直せる）
  - 「質問として送る」で入力に誤りがあっても、それまでのやり取りが消えない
  - 標準のよくある質問が 170 件になった（手順 7 で取り込みます）
  【増えたもの】管理者・補佐
  - 次のときに、ホームと管理のトップに知らせが出る
      ・よくある質問のチャットで、人への暴力を書いた文があったとき（システム管理者と補佐）
      ・よくある質問のチャットで、システムやデータを壊す・消すと書いた文があったとき（システム管理者と補佐）
  - 管理者・補佐が、利用者の予備のコードを初期化できる（認証アプリも予備のコードも無くした人の対応）
  【直したもの】
  - よくある質問のチャットの判定を見直した。命に関わる文・薬を多く飲んだ文・病気や薬の文・苦情・不適切な誘い・
    チャットの決まりを書き換えさせる文などを、ほかの端末での確かめ（約 2,300 件）と組み合わせの確かめ（約 2 万件）で直した
  - 一覧とボタンが近すぎたところの間を空けた。メッセージに入れた改行が画面で改行されるようにした
  （11 月 16 日の一式を反映していない場合は、その直しも入ります: よくある質問のチャット、管理者向けの記録と知らせ、
    メニューの「ログアウト」の見切れ、画面のテーマの追加 など）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

これは画面を開いただけでは足されないので、次のコマンドで足します。
これまでの報告・利用者・設定は消えません（無いものだけを足します。何度実行しても同じ結果になります）。

□ 表示を確かめる。次のような行が出れば正しい（前回の一式を反映していない場合は、ほかの「〜を追加」の行も出ます）

     メンテナンス中のまま開発担当に連絡する（表示をそのまま写して伝える）

7. 標準のよくある質問を取り込む（管理者）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
□ メニュー →「よくある質問」の「すべての質問」の下に、
   「標準のよくある質問を取り込む（まだ載っていない ○ 件・答えの直し ○ 件）」のボタンがあることを確かめ、押す
   - 足す件数と直す件数は、前回取り込んだかどうかで変わります
   - 「答えの直し」は、標準の答えが新しくなった質問のうち、画面で一度も直していないものだけです。
     画面で直した答えは変わりません
□ 押したあと、ボタンが消え、「標準のよくある質問は、すべて載っています。」と出ることを確かめる
   （「すべての質問」の件数が 170 件以上になる）
□ チャットの欄に「パスワードを忘れた」と入れて送り、答えが出ることを確かめる
□ チャットの欄に「コメントを直したい」と入れて送り、「本文の下の「直す」で直せます」という答えが出ることを確かめる
   （前の答え「直す操作はありません」が出たときは、その質問を画面で直していたためです。開発担当に連絡してください）
□ 管理のトップの「よくある質問の記録」を開き、いま聞いた質問が記録されていることを確かめる
□ 管理のトップの「メンテナンスを終える」を押す
□ 管理者以外の人（課長代理など）で、保存ができること、よくある質問のチャットが使えることを確かめる（できれば）

   - 入れた ID と IP アドレスを見て、打ち間違い（自分や知っている人）か、心当たりのないものかを確かめる
   - 心当たりのない ID が何度も続くときは、開発担当に知らせる
   - 確かめたら「確かめた」を押す（知らせが消えます。補佐も押せます）

参考: うまくいかなかったとき
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  - 画面が真っ白・「500」などのエラーになる
      → 手順 5（migrate.php）を実行したか確かめる。実行していなければ実行する
      → それでも直らないときは、メンテナンス中のまま、開発担当に連絡する（エラーの表示と、上げたファイルの一覧を伝える）
      → 3. のバックアップがあるので、データは戻せます。自分で DB を消したり置き換えたりはしないでください
  - 案件の選択肢に「案件なし」が無い・ユーザーの編集の画面がエラーになる
      → 手順 5（migrate.php）を実行していないためです。実行してください
  - 画面の見た目が古いまま・チャットが動かない
      → Ctrl + F5 で読み直す。それでも古いときは、js/app.js と css/app.css が上書きされたか確かめる
  - 「標準のよくある質問を取り込む」のボタンが無い
      → 管理者か補佐でログインしているか確かめる（課長・課長代理などには出ません）
      → すでに全件取り込んであり、直す答えも無いときは、ボタンは出ません（「すべての質問」の件数が 170 件以上なら取り込み済み）
  - 上げたあと .htaccess が見当たらない
      → 隠しファイルを表示する設定を確かめ、一式の report-system/.htaccess と report-system/app/.htaccess を上げ直す
  - メンテナンスを終え忘れた
      → 終わる日時を過ぎると自動で終わる。急ぐときは管理のトップで「メンテナンスを終える」を押す
