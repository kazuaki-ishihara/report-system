## 6. 検証

```powershell
python tools\test\verify_all.py          # 自動検証（構文・PHP 8.3 の書き方・秘密の確認・全シナリオ・課題の対応・保管期限）
python tools\test\verify_all.py --ui     # 画面の自動操作検証も行う（Edge / Chrome をプログラムから操作）

python tools\test\verify_all.py --list   # 工程と、工程ごとの画面の番号を出す（流さない）
```

- 結果は `tools/test/output/検証記録/<日時>/結果.md`（工程ごと・画面ごとの数）と `検証項目一覧.md`（画面ごとの確かめの一覧）、一覧は `tools/test/output/検証記録/一覧.csv`（リポジトリ外）。すべての工程を `--ui` 付きで流して成功したときは、`docs/verification_items.md`（検証項目一覧）も書き直す。
- 確かめの一つ一つには、画面の番号（G-01〜G-25）か共通の単位（コード・共通・DB・道具）を付ける（検証のスクリプトの `section("G-xx", "見出し")`。そのあとの `check()` の行が `OK  [G-xx] 名前` になる）。確かめを足すときは、設計書の「検証の観点」と突き合わせ、合う画面の `section()` の下に置く。設計書の観点のうち、ほかで確かめていなかったものは `smoke_screens.py`・`smoke_viewpoints.py`、設計書で「まだ試していない」とされていたもの（時間に頼るもの・同時の新規作成・境目・二重送信など）は `smoke_edges.py`、関数の出力だけで確かめられるもの（検証の印・対象月・出力の数式と XML）は `check_units.php`、出力を Excel（あれば LibreOffice）で開くのは `check_office.py`。動いている検証環境（ポート 8100）の出力をまとめて取り出し、件数を DB と突き合わせるのは `check_outputs.py`（`--prepare` で課のある全員の報告・精算書・目標管理・要望を足す。印刷用の画面は PDF にして `--out` に置く。`verify_all.py` には入れていない）。確かめられなかったもの（ソフトが無いなど）は、結果に「未実施」として出る。
- 同時の新規作成は、検証の印（`app/config/config.php` の `verify_mode`。MR_VERIFY_DB のときだけ true。本番では常に false）のあるサーバーだけが見る見出し `X-Verify-Pause` で、報告の保存を待たせて再現する。
- 見学の道具（`tools/lib/ui_watch.py`）は既定で `app/data/watch.sqlite` を作り直す。見る用の環境のチャットの記録を残したいときは `--db app/data/watch_check.sqlite` のように別の DB を指定する。
- 途中で止めた（Ctrl+C・止める操作・サーバーが止まった）ときは、残りの工程を流さず、判定を「中断」として残す。
- ログインは、2 段階認証のコードの前後 1 区間を順に使うので、同じ人が続けてログインしても 30 秒待たない（`lib_http.next_login_code()`）。
- 検証の道具が立てる PHP の組み込みサーバーは、セッションのファイル（`sess_*`）を一時フォルダーではなく `tools/test/output/php_sessions/`（リポジトリ外）に置く（`verify_all.php_server_command()`。1 日より古いものは起動のたびに消す）。
- 画面の自動操作では、道具が作業用の Edge（一時フォルダーの `mr_ui_*`）を自分で起動し、終わったら閉じてプロファイルを消す（`tools/test/cdp.py`）。
  - Edge は新しいプロファイルでも Windows のアカウントで自動的にサインインするため、自動のサインインを止めて起動する。つないだ先がサインインしていたら、作業用のプロファイルなら閉じて消し（サインアウト）、起動し直す。利用者自身のブラウザーなら触らずに止める。
  - 検証に使うタブ以外（前の実行の残り・始めに開くページなど）は閉じる。そのため、1 つのブラウザーを 2 つの検証で同時に使わない。
- 作業端末の Claude Code では、**PowerShell ツールから起動したブラウザーは応答しない**（この実行環境の制限。30 秒で「つながりません」と止まる）。Bash ツールから実行する（`python tools/test/verify_all.py --ui`）。
- 起動済みのブラウザーにつなぐときは `--browser-port <番号>`（`--remote-debugging-port` で起動したもの）。

- 検証は自分用の DB（`app/data/verify.sqlite`）を使い、2 段階認証を飛ばさない設定で動く（環境変数 `MR_VERIFY_DB`。`app/config/config.php`）。画面を見ている `dev.sqlite`（テーマ・ログイン）と `config.local.php` には触れないので、`dev_skip_2fa` を切り替える必要はなく、検証の途中でもローカルの画面を見られる。
- 直近の結果（2026-11-18）: すべて成功（OK 1910 / NG 0・未実施 1（LibreOffice が無い）。画面の自動操作を含む。検証用の DB で実行。Edge は道具が起動）。

### 6.1 画面の自動操作を見学する（ブラウザーを表示する）

`verify_all.py --ui` はヘッドレス（画面を出さない）で速く流す。人が目で見て確かめたいときは `tools/lib/ui_watch.py` を使う。

```powershell
python tools\lib\ui_watch.py                  # ブラウザーを表示して、1 操作 0.8 秒の速さで操作する
python tools\lib\ui_watch.py --slow 1.5       # もっとゆっくり
python tools\lib\ui_watch.py --keep-open      # 終わったあともブラウザーを開いたままにする（Enter でサーバーを止める）
```
