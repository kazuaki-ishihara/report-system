# G-24 更新のお知らせ（便利機能 A）

| 項目 | 内容 |
|---|---|
| URL | `/admin/notices.php`（GET・POST）。`?edit=<ID>` で編集、`?request=<要望ID>` で要望・依頼から書く |
| ファイル | `app/pages/admin_notices.php`、`app/views/admin_notices.php`、`app/lib/notice.php`（`notices_active()`） |
| 利用者 | 書く: システム管理者・補佐。見る: 全員（ホーム） |
| 段階 | 3 |

---

## 1. 目的

システムの改善や変更を、要望を出していない人にも伝える。管理者側が題名と内容を書き、出す期間の間、全員のホームに出す。

## 2. 表示と操作

| 項目 | 内容 |
|---|---|
| 書く | 題名（必須・60 文字）、内容（1,000 文字。空でもよい）、出す日・出す最後の日（既定は今日から `notice_default_days`＝14 日）。出す最後の日が出す日より前なら保存しない。客先名らしい言葉があれば保存したうえで注意を出す |
| 一覧 | 題名・出す期間・状態（出す前／出している／終わった）・更新した人。編集・消す（確認の表示のあと） |
| ホーム | 出している（出す日 ≦ 今日 ≦ 出す最後の日）お知らせを、新しい順に 5 件まで「更新のお知らせ」の欄に出す。題名を押すと内容が開く |
| 要望・依頼から | 要望・依頼を「リリース済み」「完了」にした詳細（管理者側）に「全員への更新のお知らせを書く」。もとの要望の番号だけを残す（件名や出した人は写さない。全員に出るため） |
| 記録 | `admin notice:<ID>:create|update|delete` |

テーブル `update_notices`（DB 編）。だれが読んだかは記録しない（省いた）。
