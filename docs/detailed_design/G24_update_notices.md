# G-24 更新のお知らせ（便利機能 A）

| 項目 | 内容 |
|---|---|
| URL | `/admin/notices.php`（GET・POST）。`?edit=<ID>` で編集、`?request=<要望ID>` で要望・依頼から書く |
| ファイル | `app/pages/admin_notices.php`、`app/views/admin_notices.php`、`app/lib/notice.php`（`notices_active()`・`notice_parse_file()`）、`app/bin/post_notice.php`（反映のときに出す。§3） |
| 利用者 | 書く: システム管理者・補佐（反映のときはコマンドでも。§3）。見る: 全員（ホーム） |
| 段階 | 3 |

---

## 1. 目的

システムの改善や変更を、要望を出していない人にも伝える。管理者側が題名と内容を書き、出す期間の間、全員のホームに出す。

## 2. 表示と操作

| 項目 | 内容 |
|---|---|
| 書く | 題名（必須・60 文字）、内容（1,000 文字。空でもよい）、出す日・出す最後の日（既定は今日から `notice_default_days`＝14 日）。出す最後の日が出す日より前なら保存しない。客先名らしい言葉があれば保存したうえで注意を出す |
| 一覧 | 題名・出す期間・状態（出す前／出している／終わった）・更新した人。編集・消す（確認の表示のあと） |
| ホーム | 出している（出す日 ≦ 今日 ≦ 出す最後の日）お知らせを、新しい順に 5 件まで「更新のお知らせ」の欄に出す。題名を押すと内容が開く。内容は、改行と行の頭の字下げ（半角・全角の空白）を書いたとおりに出す（`white-space: pre-wrap`。長い行は画面の幅で折り返す） |
| 要望・依頼から | 要望・依頼を「リリース済み」「完了」にした詳細（管理者側）に「全員への更新のお知らせを書く」。もとの要望の番号だけを残す（件名や出した人は写さない。全員に出るため） |
| 記録 | `admin notice:<ID>:create|update|delete` |

テーブル `update_notices`（DB 編）。だれが読んだかは記録しない（省いた）。

## 3. 反映のときにコマンドで出す

版を上げたときに、その版で変わることを、管理者が手で書かずに全員のホームに出す。文は開発担当が版ごとに書き、差分の一式に入れる。

| 項目 | 内容 |
|---|---|
| コマンド | `php app/bin/post_notice.php --file=<お知らせ.txt> [--db=<DB>] [--dry-run]`（`app/lib/notice.php` の `notice_parse_file()`） |
| ファイルの形 | UTF-8（BOM・CRLF も読む）。「題名: 」の行（必須・60 文字）、「出す日数: 」の行（1〜365。省くと `notice_default_days`）、「---」の行、本文。ほかの行が「---」より上にあれば誤り |
| 署名 | 本文の最後に「以上、システム管理補佐（AI）より」（`NOTICE_AI_SIGNATURE`）を付ける。すでに付いていれば重ねない。本文が空なら署名だけ。署名を含めて 1,000 文字まで |
| 書いた人 | 空（`created_by`・`updated_by` が NULL）。一覧の「更新した人」は空になり、署名で人が書いたお知らせと見分ける。画面で直すと、直した人が入る |
| 出す期間 | 流した日から、出す日数のあいだ |
| 二重に出さない | 同じ題名・同じ本文のお知らせがあれば書き込まない（手順を流し直しても 1 件） |
| 断る | 題名がない・61 文字以上、本文が署名を含めて 1,001 文字以上、「---」の行がない、出す日数が範囲の外、読めない行、制御文字。何も書き込まず、終了コード 1 |
| `--dry-run` | 題名・出す期間・本文（署名つき）を出すだけで、書き込まない |
| 記録 | `admin notice:<ID>:create_cli`（操作した人は空） |
| 差分の一式 | `tools/deploy/build_diff_package.py --notice <ファイル>` で、一式に「お知らせ.txt」を入れ、反映手順.txt に「5. 更新のお知らせを出す」を足す（www の外に上げ、`--dry-run` で確かめてから流し、終わったら消す）。上げる版に `post_notice.php` が無い、「---」の行が無いときは一式を作らない |

検証: `tools/test/smoke_cli.py`（工程 cli。境目の両側: 題名 60／61 文字、本文 1,000／1,001 文字、出す日数の省略と 0）。
