# G-25 よくある質問（便利機能 J）

| 項目 | 内容 |
|---|---|
| URL | `/faq.php`（GET・POST）。`?edit=<ID>` で直す、`?request=<要望ID>` で要望・依頼の質問から載せる |
| ファイル | `app/pages/faq.php`、`app/views/faq.php` |
| 利用者 | 見る: 全員（メニューの見出し「アカウント」に「よくある質問」）。書く・直す・消す・並べ替える: システム管理者・補佐 |
| 段階 | 3 |

---

## 1. 目的

使い方でよく聞かれることと答えを、全員が見られるようにする。

## 2. 表示と操作

| 項目 | 内容 |
|---|---|
| 一覧 | 質問を並び順に出し、押すと答えが開く。管理者側には「直す」「↑」「↓」「消す」 |
| 載せる | 質問（必須・200 文字）、答え（必須・2,000 文字・改行可）。100 件まで |
| 要望・依頼から | 種類が「質問」で閉じた要望・依頼の詳細（管理者側）に「よくある質問に載せる」。もとの要望の番号だけを残し、質問と答えは管理者側が書き直す（出した人の文や名前は出さない） |
| 部下・確認者の操作 | 載せる・直す・消すは 403 |
| 記録 | `admin faq:<ID>:create|update|delete` |

テーブル `faq_entries`（DB 編）。各画面の「？ この画面の使い方」からも開ける（共通編）。
