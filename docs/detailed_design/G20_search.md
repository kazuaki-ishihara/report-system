# G-20 検索

| 項目 | 内容 |
|---|---|
| URL | `/reports/search.php?search=1&scope=<department|mine>&from=YYYY-MM&to=YYYY-MM&dept=<課ID>&choice=<項目ID>:<コード>&q=<キーワード>`（GET） |
| ファイル | `app/pages/search.php`、`app/views/search.php`、`app/lib/search.php` |
| 利用者 | 全員（確認者・課長は担当の課の報告、だれでも自分の報告） |
| 主な端末 | PC・スマートフォン |
| 段階 | 3 |
| 関連する機能 | F-15 |

---

## 1. 目的

過去の報告から、特定の状況（例: 作業フェーズが「要件定義」、自由記述に「在庫」）の報告を探す。

## 2. 表示の条件と権限

- だれでも開ける。探す範囲（`scope`）は「担当の課の報告」（`department`。確認者の課が 1 つ以上ある人だけ。既定）か「自分の報告」（`mine`。確認者でない人は常にこれ）。
- 自分の報告は、下書きも含めて探す（課の条件は使わない）。
- 担当の課の報告は、確認者の課が 1 つ以上ある人（`reviewable_departments()`）だけ（管理者でも、確認者でない課の報告の中身は見られない（共通編 §10.2）。）。メニューの「検索」は全員に出す（見出し「報告」）。
- 担当の課の報告で探すのは、確認者の課の（課を移った人の、移る前の報告も含む）、提出済み・確認完了の報告だけ。下書き・削除済み・移行データは探さない。1 件ずつ `can_view_report()` でも確かめる。
- 「限定」の項目は、その報告の限定を見られる人（本人・課長。`can_view_restricted()`）にだけ、キーワードで探して見せる。選択式の条件には「限定」の項目を使えない。
- 保管期限で自由記述を消した報告では、自由記述を探さない。

## 3. 画面の配置

```text
┌──────────────────────────────┐
│ 検索                            │
│ 対象月 [2026-09] 〜 [2026-11]     │
│ 課 [担当のすべての課 ▼]          │
│ 選択式の値 [指定しない ▼]          │
│   （項目ごとのまとまりで「作業フェーズ: 要件定義」など） │
│ キーワード [在庫          ]       │
│ [探す]                          │
├──────────────────────────────┤
│ 3 件                            │
│ 山田さん 2026年10月 [確認完了]      │
│   P-0001 担当内容: …の在庫の引当処理を担当… │
└──────────────────────────────┘
```

## 4. 表示項目

| 項目 | 内容 |
|---|---|
| 対象月 | 既定は、対象月（G-03 §4.3）の 2 か月前から対象月まで |
| 探す範囲 | 確認者の課がある人に「担当の課の報告」「自分の報告」を出す。ない人には出さない（自分の報告だけ） |
| 課 | 既定は「担当のすべての課」。「担当の課の報告」のときだけ使う |
| 選択式の値 | 有効で「限定」でない選択式（`select`・`radio`・`checkbox`・`multi_check`）の項目のうち、共通の項目と見られる課の項目。項目ごとのまとまりで「項目名: 選択肢」（`checkbox` は「はい」） |
| 結果 | 対象月の新しい順・氏名の順に、氏名・対象月・状態。キーワードで探したときは、見つかった場所（案件コードと項目名）と前後の文（見つかった位置の 20 文字前から 60 文字）を 5 か所まで。押すと G-05 |
| 件数 | 200 件まで。超えたら「（200 件まで出しています。条件を足して絞ってください）」 |

## 5. 入力項目と確認

| 項目 | 確認 |
|---|---|
| `from`・`to` | 年月の形でなければ 400。始め > 終わりなら「対象月の始めは、終わりと同じ月かそれより前にしてください」、24 か月を超えたら「対象月は 24 か月以内にしてください」（どちらも探さない） |
| `dept` | 空か、見られる課の ID。それ以外は 403 |
| `choice` | 空か、`<項目 ID>:<コード>`。選べる項目と、その有効な選択肢（`checkbox` は `1`）でなければ 400 |
| `q` | 前後の空白を除く。50 文字まで、制御文字は不可（「キーワードは 50 文字以内にしてください」） |

## 6. 操作と処理

自由記述は暗号化しているため DB では探せない（共通編 §8.3）。次の順で探す（`search_reports()`）。

1. 課・対象月・状態（提出済み・確認完了）・選択式の値で、DB で報告を絞る。選択式の値は「限定」でないので暗号化しておらず、`report_field_values` で絞れる（`multi_check` は JSON の中にコードがあるか）。
2. キーワードがあり、絞った報告が `search_decrypt_limit`（既定 2,000）件を超えるときは、探さずに「キーワードで探す報告が N 件あり、上限（2000 件）を超えています。対象月・課・選択式の値で絞ってください。」を出す。
3. 1 件ずつ、見られるかを確かめる。キーワードがあれば、報告の値を復号し、項目マスタで「検索の対象」（`report_fields.is_searchable = 1`）にした項目の値（選択式は選択肢の表示名、表は各セル）と、案件のコード・呼び名から探す。全角・半角、大文字・小文字は区別しない（`text_normalize()`）。
4. 200 件で打ち切る。

検索の対象の初期値: 初期の様式（`app/bin/seed_template.php`）では、自由記述（「限定」を除く）を検索の対象にする。項目マスタ（G-12）で変えられる。

## 7. メッセージ

| 状況 | 文言 |
|---|---|
| 該当なし | 該当する報告はありません。 |
| 件数 | N 件 |
| 上限を超えた | キーワードで探す報告が N 件あり、上限（M 件）を超えています。対象月・課・選択式の値で絞ってください。 |
| 200 件で打ち切った | （200 件まで出しています。条件を足して絞ってください） |

## 8. 記録

`view` に `search:dept=<課ID|all|mine>;from=…;to=…;choice=<項目ID:コード|->;keyword=<yes|no>`。キーワードの中身は、客先名などが入りうるので記録しない。

## 9. 検証の観点

`tools/test/smoke_features.py` で確かめる。

- キーワードで自由記述が見つかり、前後の文が出る。案件コードでも見つかる（全角・半角を区別しない）。
- 選択式の値で探せる。下書きは出ない。対象月の範囲で絞れる。
- 見られない課の報告は出ない。「限定」の項目は課長には見つかり、課長でない確認者には見つからない。
- 部下も開けて、自分の報告（下書きを含む）だけが見つかる。確認者も「自分の報告」に切り替えられる。見られない課の指定は 403、選択肢にない値は 400。始め > 終わりは知らせる。
- 記録に条件が残り、キーワードの中身は残らない。

自動の検証でまだ試していないもの: 上限（2,000 件）を超えたときの案内（件数を用意できないため）。
