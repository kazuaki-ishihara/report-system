# G-18 コメントの一覧

| 項目 | 内容 |
|---|---|
| URL | `/reports/comments.php?tab=<sent|received>&status=<unresolved|open|answered|resolved>`（GET） |
| ファイル | `app/pages/comment_list.php`、`app/views/comment_list.php` |
| 利用者 | 全員（確認者・課長は「自分が出したコメント」、本人は「自分の報告へのコメント」） |
| 主な端末 | スマートフォン・PC |
| 段階 | 3 |
| 関連する機能 | F-07 |

---

## 1. 目的

コメントのやり取りを、報告をまたいで追えるようにする。確認者は「回答あり」（本人が返信したもの）を探して解決に、本人は「回答待ち」を探して返信する。ホームには件数と 5 件までしか出ないため、その続きを見る画面。

## 2. 表示の条件と権限

- ログインしている人なら開ける。出すのは、今その報告を見られる（共通編 §10.2）コメントだけ。確認者から外れた・課を移ったなどで見られなくなった報告のコメントは出さない。
- 「限定」の項目へのコメントは、限定を見られる人（本人・課長）にだけ出す。管理者でも、確認者でない課の報告の中身は見られない（共通編 §10.2）。
- 削除したコメント・削除した報告のコメントは出さない。

## 3. 画面の配置

```text
┌──────────────────────────────┐
│ コメント                        │
│ [自分が出したコメント] [自分の報告へのコメント] │
│ [未解決（回答待ち・回答あり）▼] [表示]   │
├──────────────────────────────┤
│ [回答あり] 山田さん 2026年10月 ／ P-0001 作業フェーズ │
│  追加情報の依頼・鈴木 11-02 10:00・返信 1 │
│  結合テストに入った理由を教えてください      │
└──────────────────────────────┘
```

## 4. 表示項目

| 項目 | 内容 |
|---|---|
| タブ | `sent`: 自分が出した最初のコメント。`received`: 自分の報告への最初のコメント。既定は、確認者（どこかの課の `department_reviewers`）なら `sent`、それ以外は `received`。確認者でない人には `sent` のタブを出さない（URL で開いても、自分が出したものしか出ない） |
| 状態 | `unresolved`（既定。回答待ち・回答あり）、`open`、`answered`、`resolved`。状態のない「連絡」（`note`）は出さない |
| 行 | 状態の札、報告の本人と対象月、対象（案件コード・項目名。項目がなければ「報告全体」）、種類、出した人と日時、返信の数、本文の先頭（改行を空白にして 80 桁まで） |
| リンク | 押すと G-05 のそのコメント（`view.php?id=…#comment-<ID>`） |
| 件数 | 新しい順に 200 件まで。超えたら「新しい 200 件まで出しています。」 |
| ホームから | 本人の「回答待ちのコメント」に「コメントの一覧」（`tab=received&status=open`）。確認者の課の欄に、回答ありがあれば「回答ありのコメント」（`tab=sent&status=answered`） |
| メニュー | 全員に「コメント」 |

## 5. 入力項目と確認

`tab`・`status` は上の値だけ。ほかの値は既定として扱う。

## 6. 操作と処理

1. `report_field_comments` の最初のコメント（`parent_id IS NULL`）で、削除されていない、状態が条件に合う、`sent` なら自分が出した・`received` なら自分の報告へのものを、新しい順に 200 件読む。
2. 1 件ずつ、報告を見られるか（`can_view_report()`）、「限定」の項目なら限定を見られるか（`can_view_restricted()`）を確かめ、見られないものは除く。
3. 本文を復号して先頭を出す（復号できなければ本文は出さない）。

## 7. メッセージ

| 状況 | 文言 |
|---|---|
| 該当なし | 該当するコメントはありません。 |
| 200 件を超えた | 新しい 200 件まで出しています。 |

## 8. 記録

なし（G-05 を開いたときに、本人以外なら G-05 の記録が残る）。

## 9. 検証の観点

`tools/test/smoke_features.py` で確かめる。

- 本人の既定は「自分の報告へのコメント」で回答待ちが出る。確認者の既定は「自分が出したコメント」で、本人が返信すると「回答あり」と返信の数が出る。
- 状態で絞り込める。ほかの人の報告へのコメントは出ない。
- 確認者から外れると、その課の報告へのコメントは出ない。
