# G-06 自分の報告一覧

| 項目 | 内容 |
|---|---|
| URL | `/reports/mine.php`（GET。`?page=n` で次のページ） |
| 利用者 | 全員（自分の報告） |
| 主な端末 | スマートフォン |
| 段階 | 1 |
| 関連する機能 | F-05、F-06 |

---

## 1. 目的

自分の過去の報告を月ごとに見て、開く。

## 2. 表示の条件と権限

本人の報告だけ（削除したものは出さない）。

## 3. 画面の配置

```text
┌──────────────────────────┐
│ ← ホーム                   │
│ 自分の報告                  │
├──────────────────────────┤
│ 2026年11月  [下書き]         │
│ 2026年10月  [確認完了] [回答待ち 1] チェック 3/3 │
│ 2026年 9月  [確認完了] チェック 3/3 │
│ ...                       │
│ [ もっと見る ]              │
└──────────────────────────┘
```

## 4. 表示項目

| 項目 | 内容 |
|---|---|
| 対象月 | 新しい順。12 件ずつ。「もっと見る」で次のページ（`?page=n+1`）を開く |
| 状態 | 下書き／提出済み／確認完了。移行したデータは「移行データ」 |
| 回答待ち | `open` の最初のコメントの件数（あれば） |
| チェック | 「チェック n/m」（下書き以外で、確認者が 1 人以上いるとき）。n はその報告の `report_reviews` のうち今の revision でチェック済みの件数（今の確認者かどうかは問わない）、m は報告の課の確認者のうち本人を除いた人数 |

本文は出さない（復号しない）。

## 5. 入力項目と確認

`page`（1 以上の整数。正しくなければ 400）。

## 6. 操作と処理

1. `report_records` を `user_id = 自分 AND deleted_at IS NULL` で、`period` の新しい順、`id` の新しい順。
2. 件数は `report_field_comments`・`report_reviews`・`department_reviewers` から集計。
3. 行を押すと、下書きは G-04、それ以外（提出済み・確認完了・移行データ）は G-05。

## 7. メッセージ

| 状況 | 文言 |
|---|---|
| 報告がない | まだ報告がありません。[今月の報告を作る]（ボタンの行き先はホーム） |

## 8. 記録

なし。

## 9. 検証の観点

- ほかの人の報告が出ない。削除した報告が出ない。
- 移行データ（同じ月に 2 件）も両方出る。

自動の検証で試しているのは、2 か月分が出て G-05 へのリンクになることだけ。
