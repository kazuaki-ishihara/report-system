# G-06 自分の報告一覧

| 項目 | 内容 |
|---|---|
| URL | `/reports/mine.php`（GET） |
| 利用者 | 全員（自分の報告） |
| 主な端末 | スマートフォン |
| 段階 | 1 |
| 関連する機能 | F-05、F-06 |

---

## 1. 目的

自分の過去の報告を月ごとに見て、開く。

## 2. 表示の条件と権限

本人の報告だけ（削除したものは出さない）。

## 3. 画面の配置

```text
┌──────────────────────────┐
│ ← 自分の報告               │
├──────────────────────────┤
│ 2026年11月  下書き      >  │
│ 2026年10月  確認完了    >  │
│   回答待ち 1                │
│ 2026年 9月  確認完了    >  │
│ ...                       │
│ [ もっと見る ]              │
└──────────────────────────┘
```

## 4. 表示項目

| 項目 | 内容 |
|---|---|
| 対象月 | 新しい順。12 件ずつ（「もっと見る」で次の 12 件） |
| 状態 | 下書き／提出済み／確認完了。移行したデータは「移行データ」 |
| 回答待ち | `open` のコメントの件数（あれば） |
| チェック | 「チェック 3/5」（提出済み・確認完了のとき） |

本文は出さない（復号しない）。

## 5. 入力項目と確認

`page`（1 以上の整数）。

## 6. 操作と処理

1. `report_records` を `user_id = 自分 AND deleted_at IS NULL` で `period` の新しい順。
2. 件数は `report_field_comments`・`report_reviews` から集計。
3. 行を押すと、下書き・提出済みは G-04、確認完了・移行データは G-05。

## 7. メッセージ

| 状況 | 文言 |
|---|---|
| 報告がない | まだ報告がありません。[今月の報告を作る] |

## 8. 記録

なし。

## 9. 検証の観点

- ほかの人の報告が出ない。削除した報告が出ない。
- 移行データ（同じ月に 2 件）も両方出る。
