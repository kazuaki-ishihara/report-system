# G-19 コメントの定型文

| 項目 | 内容 |
|---|---|
| URL | `/admin/comment_templates.php?scope=department&dept=<課ID>`（課の定型文）、`/admin/comment_templates.php?scope=mine`（自分の定型文）（GET: 一覧。POST: `action` = `add`・`update`・`delete`・`move_up`・`move_down`） |
| ファイル | `app/pages/comment_templates.php`、`app/views/comment_templates.php`、`app/lib/report.php`（`comment_templates_of()`・`comment_template_manageable_departments()`） |
| 利用者 | 課の定型文: 課長（その課の最終確認者）。自分の定型文: 確認者（課長を含む） |
| 主な端末 | PC |
| 段階 | 3 |
| 関連する機能 | F-07 |

---

## 1. 目的

確認者が報告にコメントするとき、よく使う文（「完了の見込みを教えてください」など）を選んで入れられるようにする。課長が課ごとに用意する「課の定型文」と、確認者がそれぞれ自分だけ用に用意する「自分の定型文」がある。

## 2. 表示の条件と権限

- タブ「課の定型文」（`scope=department`）と「自分の定型文」（`scope=mine`）。既定は、課長なら課の定型文、課長でない確認者なら自分の定型文。
- 自分の定型文: 確認者（どこかの課の `department_reviewers`）なら開ける。自分の定型文だけを見る・変える（`personal_comment_templates`。ほかの人の定型文の ID を送ると 404）。確認者でない人は 403。
- 課の定型文: 開ける・変えられるのは、有効な課の課長（`department_reviewers.is_final = 1`）だけで、自分が課長の課の定型文だけ。ほかの人（確認者・部下・課長でない管理者）は 403。別の課を `dept` に指定すると 403、別の課の定型文の ID を送ると 404。
- メニューの「コメントの定型文」は確認者（課長を含む）に出す。
- 使うのは G-05 のコメント欄。報告の課の定型文と、コメントする人の自分の定型文を、まとまり（「課の定型文」「自分の定型文」）に分けて出す。

## 3. 画面の配置

```text
┌─────────────────────────────┐
│ コメントの定型文                │
│ [A課 ▼] [表示]                 │
├─────────────────────────────┤
│ [完了の見込みを教えてください   ]   │
│ [保存] [上へ] [下へ] [削除]       │
├─────────────────────────────┤
│ 定型文を追加                     │
│ [                         ]    │
│ [追加]                          │
└─────────────────────────────┘
```

G-05 のコメント欄:

```text
[追加情報の依頼（回答を求める）▼]
[定型文を選ぶ（本文に入ります）▼]   ← 定型文があるときだけ
[                          ]   ← 選ぶと本文に入る（本文があれば改行して足す）
[コメントする]
```

## 4. 表示項目

| 項目 | 内容 |
|---|---|
| 課 | 課長として管理できる課が 2 つ以上なら選ぶ。既定は最初の課 |
| 一覧 | 並び順（`sort_order`、`id`）。1 件ずつ、本文の欄と「保存」「上へ」「下へ」「削除」 |
| 追加 | 30 件未満のときだけ出す。入力の誤りでは、入れた文を残して誤りを出す |
| G-05 の選択 | 選択肢は本文の先頭 60 桁（改行は空白）。選ぶと本文に入り、選択は「定型文を選ぶ」に戻る。客先名らしい言葉の注意も出し直す。JavaScript が動かないときは何もしない |

## 5. 入力項目と確認

| 項目 | 確認 |
|---|---|
| 本文 | 前後の空白を除く。必須。300 文字まで。改行は可、制御文字は不可（共通の `validate_text()`） |
| 件数 | 課ごとに 30 件まで。超えると「定型文は 30 件までです」 |

## 6. 操作と処理

共通: CSRF（共通編 §3）→ 課長か（403）→ 送信の番号（控えは `comment_template.<action>`）→ 処理 → 同じ課の一覧へ転送。

| `action` | 処理 |
|---|---|
| `add` | 並び順の最後（最後の `sort_order` + 10）に入れる。「定型文を追加しました」 |
| `update` | 本文を変える。誤りなら「定型文は 300 文字以内にしてください」などを出して戻す（変えない）。「定型文を保存しました」 |
| `delete` | 確認の表示「この定型文を削除します。よろしいですか？」のあと消す（定型文はコメントから参照しないので、物理削除）。「定型文を削除しました」 |
| `move_up`・`move_down` | 隣と入れ替え、1 つのトランザクションで並び順を 10 刻みに振り直す。端では何もしない |

## 7. メッセージ

| 状況 | 文言 |
|---|---|
| 追加した | 定型文を追加しました |
| 保存した | 定型文を保存しました |
| 削除した | 定型文を削除しました |
| 空 | 定型文を入れてください |
| 30 件を超える | 定型文は 30 件までです |
| 1 件もない | 定型文はまだありません。 |

## 8. 記録

`admin` に `comment_template:<ID>:create`・`update`・`delete`（自分の定型文は `personal_comment_template:<ID>:…`）。本文は記録しない。

## 9. 検証の観点

`tools/test/smoke_features.py`（サーバー）と `tools/test/ui_check.py`（選ぶと本文に入る）で確かめる。

- 課長は追加・編集・並べ替え・削除ができる。空は追加できない。
- 課長でない確認者・部下・別の課の課長・課長でない管理者は開けない。別の課の定型文は消せない。
- G-05 のコメント欄に、報告の課の定型文の選択が出て、選ぶと本文に入る。
- 自分の定型文: 確認者は足せて、コメント欄に課の定型文と並んで出る。ほかの人には出ない・消せない。部下は開けない。
