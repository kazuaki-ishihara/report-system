# G-11 臨時の調査の管理

| 項目 | 内容 |
|---|---|
| URL | `/surveys/manage.php`（GET: 一覧）、`/surveys/survey_edit.php?id=`（GET: 作成・編集、POST: 保存・公開・締め切り・複製・削除）、`/surveys/result.php?id=`（GET: 回答の一覧・集計） |
| 利用者 | 課長、管理者 |
| 主な端末 | PC |
| 段階 | 2 |
| 関連する機能 | F-14 |

---

## 1. 目的

課の外からの依頼などを受けて、課長が臨時の調査を作り、課の人に答えてもらい、結果を見る。

## 2. 表示の条件と権限

- 課長は、自分の課の依頼だけ。管理者は全課。
- 対象者は、作った課長の課の人（管理者は全課・人の指定ができる）。
- 結果の閲覧: `detail` なら個人の回答も、`summary` でも課長は個人の回答を見られる（依頼元に渡す出力が集計だけになる）。「限定」の質問は課長と管理者だけ。

## 3. 画面の配置

**一覧**

## 4. 表示項目

### 4.1 一覧

`adhoc_requests`（削除されていないもの）。回答数は `adhoc_responses.submitted_at` の件数 / 対象者数。

### 4.2 結果（`result.php`）

| 表示 | 内容 |
|---|---|
| 集計 | 選択式の質問ごとに、選択肢ごとの件数と割合。未回答の人数 |
| 個人の回答 | 回答者ごとの回答（自由記述は押したときに復号）。「限定」は課長・管理者のみ |
| 未回答者 | 名前の一覧（催促の機能は作らない。基本設計書 §1.6） |
| 出力 | G-10 へ（対象を「臨時の調査」にして開く） |

## 5. 入力項目と確認

| 項目 | 確認 |
|---|---|
| 題名 | 必須、1〜100 文字 |
| 依頼元・目的 | 各 0〜100・0〜300 文字 |
| 回答期限 | 公開するときは必須。今日以降 |
| 結果の扱い | `summary`／`detail` |
| 対象 | 課の全員、または人の指定（1 人以上）。指定できるのは自分の課の有効な利用者 |
| 質問 | 1〜20 問。月次の項目は有効なもの。独自の質問の種類・選択肢・確認は項目マスタ（G-12）と同じ決まり |

## 6. 操作と処理

| 操作 | 処理 |
|---|---|
| 下書き保存 | `status = 'draft'` で保存。質問を入れ替える |
| ひな形として保存 | `is_template = 1` で保存（公開できない。複製して使う） |
| 公開 | 確認の表示のあと、対象を人に展開して `adhoc_request_targets` に保存、`status = 'open'`、`opened_at`。公開後は質問を変えられない（題名・目的・期限は変えられる） |
| 締め切り | 確認の表示のあと `status = 'closed'`、`closed_at`。期限を過ぎたものは、開いたときに自動で締め切る |
| 複製 | 質問と設定を写して、新しい下書きを作る（対象・期限は空） |
| 月次の項目へ移す | 独自の質問を、課別項目として項目マスタ（G-12）の作成画面に写して開く（保存は G-12 で行う） |
| 削除 | 確認の表示のあと `deleted_at`。回答がある依頼も削除できるが、30 日間は管理者が戻せる |

月次の項目を質問にしたときは、項目マスタの定義（種類・選択肢・機密区分）を `adhoc_request_fields` に写す（あとで項目マスタを変えても、この依頼は変わらない）。

## 7. メッセージ

| 状況 | 文言 |
|---|---|
| 公開 | 公開しました。対象者のホーム画面に表示されます |
| 公開の確認 | 公開すると質問は変えられません。公開しますか？ |
| 対象者がいない | 対象者がいません |

## 8. 記録

- 公開・締め切り・削除: `admin survey:<id>:open|close|delete`。
- 結果の個人の回答を開いた: `view survey:<id>:responses`。

## 9. 検証の観点

- 確認者・部下・別の課の課長は作れない・見られない。
- 公開後に質問を変える POST が断られる。
- 対象者を、自分の課の外の人にできない（課長）。
- 締め切り後は回答できない。期限を過ぎると自動で締め切られる。
- ひな形は公開できない。
