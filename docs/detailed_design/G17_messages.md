# G-17 メッセージ

| 項目 | 内容 |
|---|---|
| URL | `/admin/messages.php?screen=&q=&changed=`（GET: 一覧。POST: `action` = `save`・`reset`・`delete_unused`） |
| ファイル | `app/pages/admin_messages.php`、`app/views/admin_messages.php`、`app/lib/message.php`、`app/lib/messages_catalog.php`（自動で作る） |
| 利用者 | 管理担当の課（システム 2 部システム 2 課）の課長 |
| 主な端末 | PC |
| 段階 | 3 |
| 関連する機能 | F-24 |

---

## 1. 目的

画面に出す文言（操作の結果・入力の誤り・エラー画面・確認の表示・JavaScript の表示）を、課長が画面から変えられるようにする。プログラムを直さずに、言い回しを社内の言葉に合わせる。

## 2. 表示の条件と権限

- 開ける・変えられるのは、システムの管理担当の課（G-14 §6.7 で指定。システム 2 部システム 2 課）の課長（`department_reviewers.is_final = 1`）だけ（`msg_can_edit()`）。ほかの課の課長・管理者・確認者・部下は 403。管理担当の課が指定されていなければ、だれも変えられない。メニューの「メッセージ」もこの人にだけ出す。
- 文言は**全体で 1 つ**。どの課長が変えても、すべての課の画面に出る（課ごとには持たない）。
- G-01 ログイン・G-02 パスワードの再設定の文言と、パスワードの決まりの文言（`auth.php`）は対象外（固定）。ログイン ID の有無を推測させない文言のため。共通のエラー画面・CSRF・セッション切れの文言は対象で、G-01・G-02 にも変えた文言が出る。
- 画面の見出し・項目名・ボタン名・メニュー・出力の列名は対象外。

## 3. 画面の配置

```text
┌──────────────────────────────────────┐
│ メッセージ                              │
│ 全 177 件 ／ 変えた文言 2 件               │
│ [すべての画面▼] [文言で探す    ] ☐変えた文言だけ [絞り込む] │
├──────────────────────────────────────┤
│ [G-04 報告の作成・編集] [変更済み] 佐藤 2026-11-13 10:00 │
│ 既定: 下書きを保存しました                 │
│ 画面に出す文言                           │
│ [下書きを保存しました。あとで提出してください ] │
│ [保存] [既定に戻す]                       │
├──────────────────────────────────────┤
│ [共通（入力の確認）]                       │
│ 既定: {max} 文字以内にしてください（今 {length} 文字）│
│ 画面に出す文言（差し込み: {length}・{max}）    │
│ [                                  ] [保存] │
└──────────────────────────────────────┘
（使われていない文言があれば、下に一覧と [消す]）
```

## 4. 文言の仕組み

| 項目 | 内容 |
|---|---|
| 書き方 | コードでは文言を `msg('既定の文言')` で包む。差し込みは `{name}` で書き、`msg('{max} 文字以内にしてください', ['max' => 100])` で値を入れる。ビューの確認の表示は `data-confirm="<?= h(msg('…')) ?>"` |
| 鍵 | 既定の文言そのもの。同じ文言を複数の画面で使っていれば、変えるとすべてに出る |
| 改行 | 文言に改行を入れられる。画面では改行して出す（メッセージの欄・入力の誤り・エラー画面は `h_lines()` で `<br>`、JavaScript の表示は CSS の `white-space: pre-line`）。確認の表示（ブラウザーの確認）も改行して出る。ログイン・再設定の画面の文言は固定なので改行しない |
| 保存 | 変えた文言だけを `ui_messages` に持つ（DB 編）。1 回の要求で 1 度だけ読む（`msg_overrides()`）。DB に届かないときは既定の文言を出す |
| JavaScript | `app.js` の文言は `M('既定の文言', {name: 値})`。`layout.php` が `body` の `data-msgs` に、既定の文言 => 画面に出す文言を JSON で入れる（`msg_js_map()`。一覧は `message.php` の `JS_MESSAGES`） |
| 一覧 | `tools/lib/msg_catalog.py` が、コードの `msg('…')`・`M('…')`・`JS_MESSAGES` を集めて `app/lib/messages_catalog.php` を作る（手で直さない）。画面の名前はファイル名から決める |
| 確かめ | `msg_catalog.py --check` で、一覧が最新か、`msg()` の最初の引数が文字列そのものかを確かめる（自動検証に組み込み）。文言を足したり変えたりしたら、`python3 tools/lib/msg_catalog.py` で作り直す |
| 既定の文言を変えたとき | プログラムの更新で既定の文言が変わると、その文言の変更は画面に出なくなる。G-17 の「使われていない文言」に出すので、新しい文言で変え直してから消す |

## 5. 入力項目と確認

| 項目 | 確認 |
|---|---|
| `msg_key`（隠し項目） | 一覧（`messages_catalog.php`）にある文言。なければ 404 |
| 画面に出す文言 | 改行を LF にそろえ、前後の空白を除く。空は不可（「既定に戻す」を使う）。500 文字まで。改行は可、ほかの制御文字は不可。差し込みの名前の集合が既定の文言と同じ（消す・足すは不可） |
| 絞り込み | `screen` は一覧にある画面の名前（ほかは無視）。`q` は 100 文字まで、既定の文言か変えた文言に含まれるもの。`changed=1` は変えた文言だけ |

## 6. 操作と処理

共通: CSRF（共通編 §3）→ 課長か（403）→ 送信の番号（控えは `admin.message.<action>`）→ 処理 → 同じ絞り込みの一覧へ転送（その文言の位置 `#m-<SHA-1 の先頭 10 文字>` へ）。

| `action` | 処理 |
|---|---|
| `save` | 確かめて、誤りなら保存せずに、入れた文言と誤りをその文言の欄に出す。既定と同じ文言なら変えた記録を消す。それ以外は `ui_messages` に入れる（あれば上書き。`updated_by`・`updated_at`）。「文言を保存しました。すべての課の画面に反映されます」 |
| `reset` | 確認の表示「既定の文言に戻します。よろしいですか？」のあと、`ui_messages` の行を消す。変えていなければ 404。「既定の文言に戻しました」 |
| `delete_unused` | 一覧にない（使われていない）変更だけを消す。一覧にある文言なら 400、変えていなければ 404。「使われていない文言を消しました」 |

## 7. メッセージ

| 状況 | 文言 |
|---|---|
| 保存した | 文言を保存しました。すべての課の画面に反映されます |
| 既定に戻した | 既定の文言に戻しました |
| 使われていない文言を消した | 使われていない文言を消しました |
| 空 | 文言を入れてください（元に戻すときは「既定に戻す」） |
| 長すぎる | 文言は 500 文字以内にしてください |
| 使えない文字 | 文言に使えない文字が入っています |
| 差し込みが違う | 差し込み（{names}）は、そのまま残してください。ほかの差し込みは足せません |

この画面の文言も G-17 で変えられる。

## 8. 記録

`admin` に `message:update:<鍵の SHA-1 の先頭 10 文字>`（保存）、`message:reset:<同>`（既定に戻す・使われていない文言を消す）。文言の中身は記録しない。

## 9. 検証の観点

`tools/test/smoke_messages.py`（29 件）で確かめる。

- 課長だけが開ける・変えられる。部下・確認者・課長でない管理者は 403（POST も）。メニューも課長にだけ出る。
- 変えた文言が、ほかの課の人の画面、エラー画面、JavaScript（`data-msgs`）に出る。
- 差し込みを消す・足す、空、501 文字は保存できない。改行は入れられ、画面で改行して出る。一覧にない文言は 404。
- 既定と同じ文言で保存すると記録を残さない。既定に戻せる。使われていない文言を消せる。
- 絞り込み（変えた文言だけ・文言で探す）ができる。記録に残る。
- G-01・G-02 の文言は一覧にない。
