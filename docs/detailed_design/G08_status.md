# G-08 提出状況

| 項目 | 内容 |
|---|---|
| URL | `/status/index.php?period=YYYY-MM&dept=<課ID>&filter=<絞り込み>`（GET） |
| 利用者 | 確認者、課長、管理者 |
| 主な端末 | スマートフォン・PC |
| 段階 | 2 |
| 関連する機能 | F-13 |

---

## 1. 目的

対象月の課の全員について、提出・チェック・回答待ちの状況を一覧で見る。確認者は「自分が未チェック」に絞って順に見る。

## 2. 表示の条件と権限

- 確認者・課長は、自分が確認者の課だけ（`dept` に別の課を指定したら 403）。管理者は全課。
- 中身（値・コメントの本文）は出さない。

## 3. 画面の配置

```text
┌──────────────────────────┐
│ ← 提出状況                 │
│ [2026-11 ▼] [A課 ▼]        │
│ 絞り込み: [すべて ▼]         │
│  すべて／自分が未チェック／未提出│
│  ／回答待ちあり／注意の印あり   │
├──────────────────────────┤
│ 提出 8/10  完了 3  未チェック 4│
├──────────────────────────┤
│ 山田  提出済み  ✓3/5  💬1  >│
│ 鈴木  確認完了  ✓5/5       >│
│ 高橋  下書き                 │
│ 田中  未作成                 │
│ ...                       │
├──────────────────────────┤
│ [ 未チェックを順に見る ]      │
└──────────────────────────┘
```

## 4. 表示項目

| 列 | 内容 |
|---|---|
| 氏名 | 表示名。課の所属者（`users.department_id`）と、対象月にその課で報告を作った人 |
| 状態 | 未作成／下書き／提出済み／確認完了 |
| チェック | 「チェック済みの人数 / 確認者の人数」。自分の状態（未チェック・済・更新あり）の印 |
| 回答待ち | `open` の最初のコメントの件数 |
| 注意の印 | `has_warning = 1` の欄がある |
| 「変更なし」 | 先月から変更なしで提出した印 |
| 提出日時 | PC 幅のときだけ出す |

## 5. 入力項目と確認

| 項目 | 確認 |
|---|---|
| `period` | 共通編 §2。省略時は G-03 §4.3 の対象月 |
| `dept` | 整数。省略時は自分が確認者の最初の課 |
| `filter` | `all`／`unchecked`／`not_submitted`／`open_comments`／`warning` |

## 6. 操作と処理

1. 権限の確認（課）。
2. 課の所属者と、`report_records`（`department_id`・`period`、削除されていないもの）を左結合する。
3. `report_reviews` と `department_reviewers` から、チェックの人数と自分の状態を出す。
4. 下書き・未作成の行は押せない（中身は見せない）。提出済み・確認完了は G-05 へ。
5. 「未チェックを順に見る」は、自分が未チェック（更新ありを含む）の最初の報告を G-05 で開く（G-05 §6 の順送り）。

## 7. メッセージ

| 状況 | 文言 |
|---|---|
| 該当なし | 該当する人はいません |

## 8. 記録

なし（中身を出さないため）。

## 9. 検証の観点

- 確認者でない課を `dept` に指定すると 403。部下は開けない。
- 下書きの中身へのリンクが出ない。
- 絞り込みの件数が、G-03 の件数と一致する。
- 課を移った人の、移る前の月の報告が、元の課に出る（報告の `department_id` で判定）。
