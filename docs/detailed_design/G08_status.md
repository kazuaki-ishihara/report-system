# G-08 提出状況

| 項目 | 内容 |
|---|---|
| URL | `/status/index.php?period=YYYY-MM&dept=<課ID>&filter=<絞り込み>`（GET。`&go=1` で最初の未チェックへ転送） |
| 利用者 | 確認者、課長、管理者 |
| 主な端末 | スマートフォン・PC |
| 段階 | 2 |
| 関連する機能 | F-13 |

---

## 1. 目的

対象月の課の全員について、提出・チェック・回答待ちの状況を一覧で見る。確認者は「自分が未チェック」に絞って順に見る。

## 2. 表示の条件と権限

- 確認者・課長は、自分が確認者の課だけ。管理者は全課。確認者の課が 1 つもない人（管理者以外）は 403。
- `dept` が整数でなければ 400。見られない課・無効な課は 403。
- 中身（値・コメントの本文）は出さない。

## 3. 画面の配置

```text
┌──────────────────────────┐
│ ← ホーム                   │
│ 提出状況                    │
│ [2026-11] [A課 ▼] [すべて ▼] [表示] │
│  すべて／自分が未チェック／未提出│
│  ／回答待ちあり／注意の印あり   │
├──────────────────────────┤
│ 提出 8/10 ／ 確認完了 3 ／ 自分が未チェック 4 │
│ [ 未チェックを順に見る ] [ 横並び・まとめ ] │
├──────────────────────────┤
│ 山田  [提出済み] ✓3/5 [未チェック] [回答待ち 1] │
│ 鈴木  [確認完了] ✓5/5 [変更なし] │
│ 高橋  [下書き]               │
│ 田中  [未作成]               │
│ ...                       │
└──────────────────────────┘
```

- 「未チェックを順に見る」は、自分が未チェックの報告があるときだけ出す。
- 「横並び・まとめ」は G-09 へ（同じ対象月・課）。

## 4. 表示項目

| 項目 | 内容 |
|---|---|
| 集計 | 「提出 x/y ／ 確認完了 n ／ 自分が未チェック n」。y は一覧の人数 |
| 氏名 | 表示名。課の有効な所属者（`users.department_id`）と、対象月にその課で報告を作った人（移行データ・削除済みを除く。無効の人でも出す）。表示名の順 |
| 状態 | 未作成／下書き／提出済み／確認完了 |
| チェック | 「✓n/m」（提出済み・確認完了のときだけ）。n は本人を除いてチェック済みの件数（今の確認者かどうかは問わない）、m は課の確認者のうち本人を除いた人数。自分の状態は「未チェック」「更新あり」の札だけ（チェック済みのときは出さない） |
| 回答待ち | `open` の最初のコメントの件数（「回答待ち n」） |
| 注意の印 | `has_warning = 1` の欄がある（提出済み・確認完了のときだけ「注意」の札） |
| 「変更なし」 | 先月から変更なしで提出した印 |

提出日時は出さない。

## 5. 入力項目と確認

| 項目 | 確認 |
|---|---|
| `period` | 共通編 §2 の形だけを確かめる（誤りは 400）。省略時は、見ている人自身の所属課で決めた対象月（G-03 §4.3） |
| `dept` | 整数。省略時は、見られる課のうち最初の課（`sort_order`・`id` の順。管理者は全課の最初） |
| `filter` | `all`／`unchecked`／`not_submitted`／`open_comments`／`warning`。それ以外は `all` として扱う |

## 6. 操作と処理

1. 権限の確認（課）。
2. 課の所属者と、`report_records`（`department_id`・`period`、`is_legacy = 0`、削除されていないもの）を左結合する。
3. `report_reviews` と `department_reviewers` から、チェックの人数と自分の状態を出す。
4. 絞り込み: `not_submitted` は未作成と下書き、`warning` は提出済み・確認完了で注意の印があるもの。
5. 下書き・未作成の行は押せない（中身は見せない）。提出済み・確認完了は G-05 へ。
6. 「未チェックを順に見る」は、一覧の並び（表示名の順）で最初の、自分が未チェック（更新ありを含む）の報告を `view.php?id=…&seq=1` で開く。2 件目からは G-05 の順送り（`submitted_at` の順）。`filter=unchecked&go=1` で開くと、画面を出さずにそこへ転送する（G-03 から使う）。

## 7. メッセージ

| 状況 | 文言 |
|---|---|
| 該当なし | 該当する人はいません。 |

## 8. 記録

なし（中身を出さないため）。

## 9. 検証の観点

- 確認者でない課を `dept` に指定すると 403。部下は開けない（403）。
- 下書きの中身へのリンクが出ない。
- 「変更なし」の印が出る。`go=1` で最初の未チェックの報告へ転送される。
- 絞り込みの件数が、G-03 の件数と一致する。
- 課を移った人の、移る前の月の報告が、元の課に出る（報告の `department_id` で判定）。

自動の検証でまだ試していないもの: G-03 との件数の一致、下書きにリンクがないこと、課を移った人の報告。
