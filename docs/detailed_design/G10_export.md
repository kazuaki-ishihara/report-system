# G-10 出力

| 項目 | 内容 |
|---|---|
| URL | `/export/index.php`（GET: 条件の画面）、`/export/print.php`（GET: 印刷用画面）、`/export/download.php`（POST: xlsx・CSV） |
| 利用者 | 課長、管理者 |
| 主な端末 | PC（スマートフォンからは使わせない） |
| 段階 | 3 |
| 関連する機能 | F-18 |

---

## 1. 目的

課長が、課の外への報告書を作る**元ネタ**を出力する。印刷用画面（ブラウザーで PDF 保存）、Excel 形式、CSV。

## 2. 表示の条件と権限

- 課長は自分の課だけ。管理者は全課。確認者・部下は 403。
- スマートフォンからは使わせない: 画面幅と `User-Agent` で判定し、スマートフォンなら「出力は PC から行ってください」と出してボタンを出さない（サーバー側でも `User-Agent` で断る）。
- 「限定」の項目は出力しない（管理者だけ、出力するかを選べる）。
- 臨時の調査で `result_visibility = 'summary'` のものは、集計だけを出す。

## 3. 画面の配置

```text
出力
──────────────────────────────────────
対象      (●月次報告  ○臨時の調査)
対象月    [2026-11 ▼] 〜 [2026-11 ▼]（最大 12 か月）
課        [A課 ▼]
内容      (●横並び  ○まとめ  ○両方)
形式      (●印刷用画面（PDF 保存）  ○Excel（.xlsx）  ○CSV)
自由記述  [☑ 含める]
限定の項目 [☐ 含める]（管理者のみ）

この出力は記録されます。出力したファイルは社外秘として扱ってください。
[ 出力する ]
```

## 4. 表示項目

### 4.1 出力物の共通の見出し

すべての形式の先頭に入れる。

```text
社外秘
月次報告 A課 2026年11月（横並び）
出力者: 佐藤（login_id）  出力日時: 2026-12-02 10:15
```

- xlsx はシートの 1〜3 行目と、ヘッダー・フッター（印刷時に毎ページ）に入れる。
- CSV は 1〜3 行目に入れる（取り込むときは 4 行目から）。
- 印刷用画面は、毎ページの上部に出す（`@media print`）。

### 4.2 内容

- 横並び・まとめは G-09 と同じ内容。対象月を複数にしたときは、月ごとに並べる。
- 臨時の調査は、`summary` なら質問ごとの件数・割合、`detail` なら回答者ごとの回答。
- 項目は `include_in_export = 1` のもの。

## 5. 入力項目と確認

| 項目 | 確認 |
|---|---|
| 対象月 | 開始 ≦ 終了、最大 12 か月 |
| 課 | 自分が課長の課（管理者は全課） |
| 形式 | `print`／`xlsx`／`csv` |
| 臨時の調査 | 自分の課の依頼（`closed` または `open`） |

## 6. 操作と処理

1. 権限・端末の確認。CSRF（download は POST）。
2. G-09 と同じ方法で値を集める。自由記述を含めるときは、権限の範囲で復号する。
3. 形式ごとに作る。

| 形式 | 作り方 |
|---|---|
| 印刷用画面 | HTML を出し、「印刷して PDF に保存してください」の案内と印刷ボタン（`window.print()`）。A4 横、文字は 9pt 以上、表が切れるときは行の途中で改ページしない |
| xlsx | `ZipArchive` で `[Content_Types].xml`、`_rels/.rels`、`xl/workbook.xml`、`xl/worksheets/sheet1.xml`、`xl/styles.xml`、`xl/sharedStrings.xml` を組み立てる。`ZipArchive` がない環境では、zip を自前で書く（無圧縮の格納のみ） |
| CSV | UTF-8（BOM 付き）、改行 CRLF、すべての値を `"` で囲む |

4. 数式の注入を防ぐ: 値が `=` `+` `-` `@` タブ・改行で始まるときは、先頭に `'` を付ける（xlsx は文字列の型で書く）。
5. ファイル名: `report_A課_2026-11_20261202-1015.xlsx`（課名の記号は `_` に置き換え）。`Content-Disposition: attachment`、`Cache-Control: no-store`。
6. 記録 `export ...` を残してから返す。

## 7. メッセージ

| 状況 | 文言 |
|---|---|
| スマートフォン | 出力は PC から行ってください |
| 期間が長い | 対象月は 12 か月以内にしてください |
| 対象なし | 出力する報告がありません |

## 8. 記録

`export export:<種類>;period=<開始>..<終了>;dept=<課>;format=<形式>;free_text=<0|1>;restricted=<0|1>`。

## 9. 検証の観点

- 確認者・部下・別の課の課長は出力できない。スマートフォンの `User-Agent` では断られる。
- 「限定」の項目が、課長の出力に含まれない。
- `summary` の臨時の調査で、個人の回答が出力に含まれない。
- 出力物に「社外秘」・出力者・日時が入っている。
- `=1+1` などの値が数式として動かない。
- 作った xlsx が Excel と LibreOffice Calc で開ける（検証の道具では、zip の構造と XML の正しさを確かめる）。
- 出力するたびに記録が残る。
