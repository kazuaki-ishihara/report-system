# G-10 出力

| 項目 | 内容 |
|---|---|
| URL | `/export/index.php`（GET: 条件の画面。POST: 印刷用画面・xlsx・CSV） |
| ファイル | `app/pages/export.php`、`app/views/export_index.php`・`export_print.php`、`app/lib/export.php` |
| 利用者 | 課長 |
| 主な端末 | PC（スマートフォンからは使わせない） |
| 段階 | 3 |
| 関連する機能 | F-18 |

---

## 1. 目的

課長が、課の外への報告書を作る**元ネタ**を出力する。印刷用画面（ブラウザーで PDF 保存）、Excel 形式、CSV。

## 2. 表示の条件と権限

- 課長（その課の `is_final` の確認者）は自分の課だけ（`final_departments()`）。確認者・部下・課長でない管理者は GET でも 403。管理者でも、確認者でない課の報告の中身は見られない（共通編 §10.2）。
- スマートフォンからは使わせない。判定は `User-Agent` だけで行う（`iPhone|iPod|Android.*Mobile|Mobile Safari|Windows Phone`）。
  - GET: 「出力は PC から行ってください（スマートフォンにファイルを残さないため）。」と出し、フォームを出さない。
  - POST: 403「出力は PC から行ってください。」。
- 「限定」の項目は、既定では出力しない。出力する課の課長が「「限定」の項目を含める」を選んだときだけ出す（課長は画面でも限定を見られるため）。
- 臨時の調査で `result_visibility = 'summary'` のものは、集計だけを出す。

## 3. 画面の配置

```text
出力
この出力は記録されます。出力したファイルは社外秘として扱ってください。

対象      (●月次報告  ○臨時の調査)
┌ 月次報告 ─────────────────────────────
│ 課        [A課 ▼]
│ 対象月（開始〜終了。最大 12 か月） [2026-11] 〜 [2026-11]
│ 内容      (●横並び  ○まとめ  ○両方)
└──────────────────────────────────────
┌ 臨時の調査 ───────────────────────────
│ [調査の題名 ▼]
│ 「集計のみ」の調査は、集計だけを出力します。
└──────────────────────────────────────
形式      (●印刷用画面  ○Excel 形式（.xlsx）  ○CSV)
[☐ 自由記述を含める]
[☐ 「限定」の項目を含める（渡す相手を確かめてください）]
[ 出力する ]
```

- フォームは新しいタブ（`target="_blank"`）で送る。
- GET の `period`・`dept`・`type`・`survey_id` を初期値にする（G-09・G-11 の「出力へ」が使う）。
- 調査の候補は、自分が課長の課の、削除されていない・下書きでない・ひな形でない依頼（作成日時の新しい順）。

## 4. 表示項目

### 4.1 出力物の共通の見出し

すべての形式の先頭に入れる。

```text
社外秘
月次報告 A課 2026年10月〜2026年11月
出力者: 佐藤（sato）  出力日時: 2026-12-02 10:15
```

- 2 行目: 月次は「月次報告 <課名> <開始の年月>[〜<終了の年月>]」。調査は「臨時の調査 <題名>（依頼元: …）」（依頼元が空なら括弧は付けない）。
- 出力者は表示名（空ならログイン ID）と、括弧の中にログイン ID。
- xlsx: 1〜3 行目が見出し、4 行目が空行、5 行目が列の見出し。印刷のヘッダーは左に「社外秘」、右に出力者の行。フッターはページ番号「n / N」。
- CSV: 1〜3 行目が見出し、4 行目が列の見出し。
- 印刷用画面: 先頭に見出しを出す。表の見出し行は毎ページに出す。

### 4.2 内容

**月次報告**

- 列は「対象月・氏名・案件」と、課の今の様式のうち `include_in_export = 1` の有効な項目（`project` 型は除く）。自由記述は「含める」のときだけ、「限定」は課長が選んだときだけ（列名に「（限定）」を付ける）。
- 行は G-09 と同じ「人 × 案件ブロック」。対象月を複数にしたときも 1 つの表にし、対象月、表示名の順に並べる。
- 内容が「まとめ」「両方」のときは、表のあとに G-09 のまとめを足す。まとめは期間全体で 1 回作り、終了月を基準に判定する。
  - 欄ごとに「■ 欄名」「n件」の行、続けて「対象月・氏名・案件」の行。
  - 集計は「■ 項目名」「選択肢 件数」… の行。
- 「まとめ」だけのときも、列の見出しの行は出る（xlsx・CSV）。

**臨時の調査**

- 常に、選択式（`select`・`radio`・`multi_check`・`checkbox`）の質問ごとに「質問・選択肢・件数・割合」を出す。割合は回答者数に対する整数の %。`checkbox` は「はい」の件数。「限定」の質問は課長が選んだときだけ。
- `result_visibility = 'detail'` のときは、そのあとに回答者ごとの表（回答者・各質問）を足す。自由記述の質問は「含める」のときだけ、「限定」は課長が選んだときだけ。

## 5. 入力項目と確認

| 項目 | 確認 |
|---|---|
| `type` | `survey` 以外は `report` として扱う |
| `format` | `print`／`xlsx`／`csv`。それ以外は 400 |
| 課（`dept`） | 自分が課長の課。それ以外は 403 |
| 対象月（`from`・`to`） | 形が正しく、開始 ≦ 終了。最大 12 か月。外れたら 400 |
| 内容（`content`） | `table`／`summary`／`both`。それ以外は 400 |
| 臨時の調査（`survey_id`） | 削除されていない・下書きでない・自分が課長の課の依頼。外れたら 404 |
| `free`・`restricted` | `1` のときだけ含める |

## 6. 操作と処理

1. 権限・端末の確認（GET で課長でなければ 403、POST でスマートフォンなら 403）。POST は共通の CSRF の確認を通る（共通編 §3）。
2. 値を集める。月次は G-09 と同じ `compare_dataset()` で集め、自由記述を含めるときは権限の範囲で復号する。調査は回答を復号して集める。
3. 対象の報告がなければ 404「出力する報告がありません。」。
4. 記録 `export ...` を残す。
5. 形式ごとに作って返す。

| 形式 | 作り方 |
|---|---|
| 印刷用画面 | HTML を返す。ボタン「印刷する（PDF として保存）」（`window.print()`）と、案内「印刷の画面で、送信先に「PDF に保存」（Firefox では「ファイルへ出力」）を選びます。」。A4 横、余白 12mm、文字は画面で 10pt・印刷で 9pt、表の見出し行を毎ページに出し、行の途中で改ページしない |
| xlsx | zip は自前で書く（無圧縮の格納。`ZipArchive` は使わない）。中身は `[Content_Types].xml`、`_rels/.rels`、`xl/workbook.xml`、`xl/_rels/workbook.xml.rels`、`xl/styles.xml`、`xl/worksheets/sheet1.xml`。文字列はセルに直接書き（`inlineStr`）、`sharedStrings.xml` は作らない。すべて文字列のセルにする（書式も文字列）。用紙は A4 横、シート名は「報告」 |
| CSV | UTF-8（BOM 付き）、改行 CRLF、すべての値を `"` で囲む |

6. 数式の注入を防ぐ: CSV は、値が `=` `+` `-` `@` タブ・CR で始まるときに先頭へ `'` を付ける。xlsx は `'` を付けず、すべて文字列のセルで書く（数式として動かない）。
7. ファイル名:
   - 月次: `report_<課名>_<開始>[_<終了>]_<YYYYMMDD-HHMM>.<xlsx|csv>`（課名の文字・数字以外は `_` に置き換え）
   - 調査: `survey_<ID>_<YYYYMMDD-HHMM>.<xlsx|csv>`
   - `Content-Disposition: attachment; filename="export.<形式>"; filename*=UTF-8''<名前>`。共通のヘッダー（`Cache-Control: no-store` など）も付ける。

## 7. メッセージ

| 状況 | 文言 |
|---|---|
| スマートフォン（GET） | 出力は PC から行ってください（スマートフォンにファイルを残さないため）。 |
| スマートフォン（POST） | 出力は PC から行ってください。（403） |
| 開始 > 終了・形が違う | 対象月を正しく選んでください（開始 ≦ 終了）。（400） |
| 期間が長い | 対象月は 12 か月以内にしてください。（400） |
| 対象なし | 出力する報告がありません。（404） |

## 8. 記録

- 月次: `export export:report;period=<開始>..<終了>;dept=<課ID>;format=<print|xlsx|csv>;content=<table|summary|both>;free_text=<0|1>;restricted=<0|1>`
- 調査: `export export:survey;id=<ID>;format=<print|xlsx|csv>;free_text=<0|1>;restricted=<0|1>`

## 9. 検証の観点

- 確認者・部下は出力できない。スマートフォンの `User-Agent` では断られる。
- 「限定」の項目が、課長の出力に含まれない。
- `summary` の臨時の調査で、個人の回答が出力に含まれない。
- 出力物に「社外秘」・出力者・日時が入っている。CSV に BOM と見出しがある。印刷用画面が出る。
- 作った xlsx の zip の構造が正しい。
- 出力するたびに記録が残る。
- 自動の検証にまだないもの: 別の課の課長が出力できないこと、`=1+1` などの値が数式として動かないこと、XML の正しさ、Excel と LibreOffice Calc で開けること。
