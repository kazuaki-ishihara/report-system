# G-23 課の管理（課長）

| 項目 | 内容 |
|---|---|
| URL | `/admin/department.php?dept=<課ID>`（GET・POST） |
| ファイル | `app/pages/department_manage.php`、`app/views/department_manage.php`、`app/lib/admin.php`（`department_manage_member_rows()`） |
| 利用者 | 課長（その課の最終確認者）。自分が課長の課だけ |
| 主な端末 | PC |
| 段階 | 3 |

---

## 1. 目的

システム管理者はシステム全体の管理だけを行い、個々の課の管理はしない（K-042）。課の中のこと（締め日・管理の仕方・課長代理と主任・チェックする人・項目管理者・ライン）は、その課の課長が決める。

| 担当 | 行うこと |
|---|---|
| システム管理者（G-14） | 課の追加・名前・並び・有効／無効・管理担当、課長を決める、ユーザーの追加・無効・所属の課、組織の改訂（引き継ぐ課・一括 CSV） |
| 課長（この画面） | 締め日、管理の仕方（課全体／ラインごと）、課長代理・主任（確認者）と担当のライン、チェックする／しない（K-039）、項目管理者、ライン、課員のライン |

組織の改訂の一括 CSV（G-14 §6.8）では、管理者が改訂のときに確認者もまとめて入れられる。改訂のあとの変更は課長がこの画面で行う。

## 2. 表示の条件と権限

- 開けるのは、その課の課長（`department_reviewers.is_final = 1`）だけ。課長の課が 1 つもない人は 403。ほかの課（`dept`）は 403。管理者・補佐でも、課長でなければ開けない。
- メニューの見出し「管理」に「課の管理」（課長だけ）。管理のトップ（G-21）にカード。管理画面の道しるべを出す。

## 3. 画面の配置

ページの中のタブ（G-21 §5）で 3 つの節に分ける。課長の課が 2 つ以上あれば、上で課を選ぶ。

| 節 | 内容 |
|---|---|
| 基本（`#dept-basic`） | 締め日（1〜31。31 は月末。空欄はなし）、管理の仕方（課全体／ラインごと）。「保存」 |
| 確認者と課員（`#dept-members`） | この課の有効な課員と、この課の確認者（ほかの課の人・課のない人の兼務を含む）の表。列は 名前（ほかの課の人は札）・役職・ライン（ラインごとの課。課員だけ）・確認者（課長は「課長」）・担当のライン（ラインごとの課。課長は「課全体」）・チェックする（課長は「常にする」）・項目管理者。名前・ID で絞り込める。「確認者と課員を保存」（確認の表示のあと） |
| ライン（`#dept-teams`） | ラインごとに名前・有効と「保存」。「ラインを足す」 |

## 4. 操作と処理

| 操作 | 処理 |
|---|---|
| 基本の保存 | `departments.close_day`・`review_scope` を更新。締め日が 1〜31 でなければ「締め日は 1〜31（31 は月末）にしてください」。記録 `admin department:<id>:settings` |
| 確認者と課員の保存 | 表の人ごとに: 確認者の印があれば `department_reviewers`（課長の行は変えない）に担当のライン・チェックするを入れる（新しく確認者にする人は行を足す。印を外した人は行を消す。チェックの記録は残る）。項目管理者（`department_admins`）を入れ替える。課員のライン（`users.team_id`）を更新。表にない人・ほかの課のラインは 400。「確認者と課員を保存しました」。記録 `admin department:<id>:members` |
| 兼務の確認者を足す（`#dept-concurrent`。2026-11-26 指示） | 表の下の「兼務の確認者を足す」で 1 人を選ぶ（札と候補の一覧 `select.tag-picker`。候補は有効で、この課に所属していない人（課のない部長などを含む）のうち、この課の確認者・課長でなく、専門職でない人。所属の課ごとのまとまり、課のない人は「課なし」）。確認の表示のあと「兼務の確認者に足す」で `department_reviewers` に行を足す（課長ではない・ラインなし・チェックするは役職で決める `reviewer_default_does_check()`）。所属の課は変えない。足したあとは表に「ほかの課」の札つきで出るので、担当のライン・チェックする・項目管理者を表で決める。外すときは表で「確認者」の印を外して保存する。選んでいない「兼務させる人を選んでください」、もう確認者「（名前） さんは、もうこの課の確認者です」、この課の人・無効な人は 400、専門職は 400。「（名前） さんを、兼務の確認者に足しました。担当のライン・チェックするを表で決めて保存してください」。記録 `admin department:<id>:concurrent_add:<利用者 ID>`。兼務の課長は G-14 の「課長」の節で決める（課長が決めるのは確認者だけ） |
| ラインの追加・変更 | `department_teams`。名前は課の中で一意（「同じ名前のラインがあります」）。無効にすると、そのラインの人と担当の確認者のラインを外す。記録 `admin department:<id>:team_add`・`team_update` |

## 5. チェックする／しない（K-039）

- 課長代理・主任は、確認者ごとに「チェックする／しない」を持つ（`department_reviewers.does_check`）。課長は常にチェックする。
- 新しく確認者にするときの既定は、役職が課長代理なら「する」、ほか（主任など）は「しない」（画面の印の初めの状態。CSV で新しく確認者になる人も同じ。`reviewer_default_does_check()`）。
- 「しない」の人: 「チェック n/m」の m に数えない（`report_expected_reviewer_ids()`）。確認完了の条件にも入らない。報告の詳細にチェックのボタンを出さず、チェックの操作は受け付けない。ホームの未チェックの数・「未チェックを順に見る」・提出状況の「自分が未チェック」・まとめてチェックを出さない。ホームの確認の欄に「この課では、報告のチェックをしない設定です（課長が「課の管理」で決めます）。報告を見ること・コメントはできます。」を出す。
- 報告を見ること・コメントは、チェックしない人もできる（見える範囲は確認者と同じ）。

## 6. 検証の観点

`tools/test/smoke_org.py`・`ui_check.py`。

- 課長は開け、課長代理・管理者・ほかの課の課長は 403。課長のメニューに「課の管理」。
- 管理の仕方・ライン・確認者の担当のライン・課員のラインを課長が決められる。ほかの課の人のラインは 400。
- 主任を「チェックしない」にすると、m が減り、チェックのボタンが出ず、チェックを受け付けず、ホームと提出状況に未チェックを出さない。コメントはできる。
- 節のタブと、表の絞り込み。
