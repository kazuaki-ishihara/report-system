# G-09 横並び表示・状況のまとめ

| 項目 | 内容 |
|---|---|
| URL | `/status/compare.php?period=YYYY-MM&dept=<課ID>&view=<表示>`（GET） |
| 利用者 | 確認者、課長、管理者 |
| 主な端末 | PC |
| 段階 | 3 |
| 関連する機能 | F-16、F-17 |

---

## 1. 目的

課の報告を横に並べて比べる。選択式の値を使って、**終了が近い案件、人員の動きがある現場、遅延・問題がある現場**をまとめて見る。課長が課の外への報告を作る材料にする。

## 2. 表示の条件と権限

- G-08 と同じ（自分が確認者の課、管理者は全課）。
- 「限定」の項目は、課長と管理者にだけ中身を出す。確認者には列ごと出さない。
- 提出済み・確認完了の報告だけを対象にする。

## 3. 画面の配置

**横並び（`view=table`）**

```text
[2026-11 ▼] [A課 ▼]  表示: (●横並び ○まとめ)  [前月との差分を表示 ☑]  [出力へ]
┌────┬────────┬────────┬──────┬────────┬────────┐
│氏名 │案件     │フェーズ │進捗   │継続見込み│終了予定 │ …
├────┼────────┼────────┼──────┼────────┼────────┤
│山田 │P-0012  │製造・単体│遅延あり*│当分継続 │2027-03 │
│山田 │P-0020  │運用・保守│問題なし │終了の話あり*│2026-12│
│鈴木 │P-0007  │…       │…     │…       │…       │
└────┴────────┴────────┴──────┴────────┴────────┘
* = 前月から変わった値
```

**まとめ（`view=summary`）**

```text
■ 終了が近い案件（終了予定が 3 か月以内、または「終了の話あり」）  4件
  P-0020 山田 終了の話あり 2026-12   終了後の作業: なし
  ...
■ 人員の動きがある現場  2件
  P-0012 山田 増員の話あり
  ...
■ 遅延・問題がある現場  1件
  P-0012 山田 遅延あり
■ 集計
  作業フェーズ: 要件定義 1 / 基本設計 2 / 製造・単体 4 / …
  進捗: 問題なく進行 8 / 遅延あり 1 / その他 0
```

## 4. 表示項目

### 4.1 横並び

- 行は「人 × 案件ブロック」。報告全体の項目は、その人の最初の行に出す。
- 列は、その課の様式のうち `show_in_list = 1` の項目（選択式・日付・年月・数値を基本に、自由記述は「あり／なし」の印か、押して開く）。
- 前月との差分: 前月の同じ人・同じ案件の値と比べ、違えば印。前月の報告がなければ「新規」。
- 自由記述は既定では出さず、セルを押したときだけ復号して出す（一覧で大量に復号しない）。

### 4.2 まとめ

| 欄 | 条件（初期の様式の項目のコードで判定。設定で変えられる） |
|---|---|
| 終了が近い案件 | `continuation = 'ending'`、または `end_month` が対象月から 3 か月以内 |
| 人員の動き | `staffing IN ('increase', 'decrease')` |
| 遅延・問題 | `progress IN ('delayed', 'other')` |
| 集計 | 選択式の項目ごとの件数 |

判定に使う項目のコードと値は `config` の `summary_rules` に持ち、項目マスタの変更に合わせて管理者が変えられるようにする。

## 5. 入力項目と確認

G-08 と同じ（`period`、`dept`）。`view` は `table`／`summary`。`diff` は `0`／`1`。

## 6. 操作と処理

1. 権限の確認。
2. 対象の報告（提出済み・確認完了）と、`report_field_values` のうち選択式・日付・年月・数値の値を取得する（復号しない）。
3. 前月の報告の同じ値を取得し、比べる。
4. まとめは、選択式の値だけで判定・集計する（自由記述を復号しない）。
5. 自由記述のセルを開いたとき（`/status/compare.php?cell=...`、GET、JSON）は、権限を確かめてその 1 つだけを復号して返す。記録 `view report:<id>`。

## 7. メッセージ

| 状況 | 文言 |
|---|---|
| 対象なし | 提出済みの報告がありません |

## 8. 記録

- 画面を開いたとき `view compare:period=…;dept=…`。
- 自由記述のセルを開いたとき `view report:<id>`。

## 9. 検証の観点

- 確認者に「限定」の列が出ない（HTML・JSON の中にも含まれない）。
- 下書きの報告が出ない。
- まとめの件数が、選択式の値の件数と一致する。
- 項目を無効にしても、過去の月の横並びが崩れない（作成時の定義で出す）。
- 案件ブロック 0 件の人、前月の報告がない人で崩れない。
