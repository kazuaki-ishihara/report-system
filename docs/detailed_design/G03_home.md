# G-03 ホーム

| 項目 | 内容 |
|---|---|
| URL | `/index.php`（GET） |
| 利用者 | 全員 |
| 主な端末 | スマートフォン |
| 段階 | 1（提出状況・臨時の調査の欄は 2） |
| 関連する機能 | F-05、F-07、F-12、F-13、F-14 |

---

## 1. 目的

月に 1 回しか来ない人が、**今やることがすぐ分かる**入り口にする。部下には「今月の報告」と「回答待ち」、確認者には「未チェック」と「回答あり」を出す。

## 2. 表示の条件と権限

- ログインしている全員。
- 出す欄は役割で変わる（共通編 §10.1）。複数の課の確認者なら、課ごとに件数を出す。

## 4. 表示項目

### 4.1 全員

| 欄 | 内容 | 出し方 |
|---|---|---|
| 今月の報告 | 対象月（§4.3）の自分の報告の状態 | 未作成なら「今月の報告を作る」、下書きなら「続きを書く」、提出済み・確認完了なら「報告を見る」。提出済みで回答待ちがあれば「コメントに答える」 |
| 締め日 | 所属課の `close_day`（未設定なら出さない） | 締め日の 3 日前からは赤で出す |
| 回答待ちのコメント | 自分の報告への、`thread_status = 'open'` の最初のコメント | 件数と、項目名・投稿者の一覧（最大 5 件）。押すと G-05 の該当箇所へ |
| 臨時の調査 | 自分が対象で、`status = 'open'`、未回答のもの | 題名と期限。押すと G-07 |
| 前月の報告 | 前月が未提出なら「先月の報告がまだです」と出す | 押すと G-04 |

### 4.2 確認者・課長（課ごと）

| 欄 | 内容 |
|---|---|
| 未チェック | 対象月の、その課の提出済みの報告のうち、自分がチェックしていない（または「更新あり」）もの。自分の報告は除く |
| 回答あり | 自分が出したコメントのうち、`thread_status = 'answered'` のもの |
| 未提出 | その課の、対象月の報告が未作成・下書きの人数（課長のみ） |
| ボタン | 「未チェックを順に見る」→ G-05 を未チェックの順に開く。「提出状況」→ G-08 |

### 4.3 対象月の決め方

- 既定は**前月**（月次報告は前月の状況を月初に報告するため）。
- 課の `close_day` が設定されていて、今日がその日以前なら、前月のまま。過ぎていれば当月。未設定なら、毎月 1 日から月末まで前月。
- 運用に合わせて変えられるよう、決め方は `config` の値（`report_period_rule`）で切り替える。

## 5. 入力項目と確認

なし。

## 6. 操作と処理

1. 自分の報告（対象月・前月）: `report_records` を `user_id` と `period` で 2 件まで。
2. 回答待ち: `report_field_comments` で、自分の報告の `parent_id IS NULL AND thread_status = 'open' AND deleted_at IS NULL`。
3. 臨時の調査: `adhoc_request_targets` で自分が対象、`adhoc_requests.status = 'open'`、`adhoc_responses.submitted_at` が NULL。
4. 確認者: 自分が `department_reviewers` に入っている課ごとに、対象月の `report_records`（`status IN ('submitted','confirmed')`）と `report_reviews` を突き合わせる。
5. 本文は復号しない（件数と項目名だけを出す）。

## 9. 検証の観点

- 部下には確認者の欄が出ない。確認者には、自分が確認者の課の件数だけが出る。
- 自分の報告は「未チェック」に数えない。
- 「更新あり」の報告が未チェックに数えられる。
- 削除した報告・コメントが数えられない。
- 対象月が締め日の前後で正しく切り替わる。
