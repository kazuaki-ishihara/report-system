# G-03 ホーム

| 項目 | 内容 |
|---|---|
| URL | `/index.php`（GET） |
| 利用者 | 全員 |
| 主な端末 | スマートフォン |
| 段階 | 1（提出状況・臨時の調査の欄は 2） |
| 関連する機能 | F-05、F-07、F-12、F-13、F-14 |

---

## 1. 目的

月に 1 回しか来ない人が、**今やることがすぐ分かる**入り口にする。部下には「今月の報告」と「回答待ち」、確認者には「未チェック」と「回答あり」を出す。

## 2. 表示の条件と権限

- ログインしている全員。
- 出す欄は役割で変わる（共通編 §10.1）。複数の課の確認者なら、課ごとに欄を出す。確認者の欄は `department_reviewers` に入っている課だけに出す（管理者でも、入っていなければ出ない）。無効の課は出さない。

## 3. 画面の配置

```text
┌──────────────────────────┐
│ 月次報告      [≡ メニュー] │
├──────────────────────────┤
│ 山田 さん                  │
│                          │
│ ■ 2026年11月の報告         │
│   状態: 未作成              │
│   締め日: 2026-12-05        │
│   [ 今月の報告を作る ]       │ ← いちばん大きいボタン
│   2026年10月の報告がまだです。作る │
│                          │
│ ■ 回答待ちのコメント 2件     │
│   ・作業フェーズ（佐藤さん）  │
│   ・報告全体（課長さん）      │
│                          │
│ ■ 臨時の調査 1件            │
│   ・AI の利用状況 期限 2026-11-20 │
│                          │
│ ■ A課 2026年11月（確認）    │
│   未チェック 5件 ／ 回答あり 1件 ／ 未提出 2人 │
│   [ 未チェックを順に見る ] [ 提出状況 ] │
└──────────────────────────┘
```

所属の課がない人には、上に「所属の課が設定されていません。管理者に連絡してください。」を出す。

## 4. 表示項目

### 4.1 全員

| 欄 | 内容 | 出し方 |
|---|---|---|
| 今月の報告 | 見出し「YYYY年M月の報告」。対象月（§4.3）の自分の報告の状態（未作成／下書き／提出済み／確認完了） | 未作成なら「今月の報告を作る」、下書きなら「続きを書く」（どちらも G-04）、それ以外は「報告を見る」（G-05） |
| 締め日 | 所属課の `close_day` による、対象月の**翌月**の締め日（`YYYY-MM-DD`。31 や月末を超える日は月末にする）。未設定なら出さない | 残り 3 日以内（過ぎた後を含む）は赤で出す |
| 前月の報告 | 前月の報告が未作成か下書きなら「YYYY年M月の報告がまだです。」と「作る」のリンク | 押すと前月の G-04 |
| 回答待ちのコメント | 自分の報告（対象月に限らない）への、`thread_status = 'open'` の最初のコメント | 件数と、「項目名（投稿者さん）」の一覧（最大 5 件）。項目がないコメントは「報告全体」。押すと G-05 の該当のコメント（`#comment-<ID>`）へ |
| 臨時の調査 | 自分が対象で、`status = 'open'`、削除されていない、未回答のもの | 題名と「期限 YYYY-MM-DD」。期限の順。押すと G-07 |

### 4.2 確認者・課長（課ごと）

見出しは「（課名） YYYY年M月（確認）」。

| 欄 | 内容 |
|---|---|
| 未チェック | 対象月の、その課の提出済み・確認完了の報告のうち、自分がチェックしていない（または「更新あり」）もの。自分の報告と削除済みは除く |
| 回答あり | その課の報告に自分が出した最初のコメントのうち、`thread_status = 'answered'` のもの（対象月に限らない） |
| 未提出 | その課の有効な所属者のうち、対象月に提出済み・確認完了の報告がない人数（課長＝`is_final = 1` の欄だけ。確認者自身も数える） |
| ボタン | 「未チェックを順に見る」→ G-08（`filter=unchecked&go=1`）を経由して、最初の未チェックの G-05 へ。未チェックが 0 件なら出さない。「提出状況」→ G-08 |

### 4.3 対象月の決め方

- 既定は**前月**（月次報告は前月の状況を月初に報告するため）。
- 課の `close_day` が設定されていて、今日がその日以前（月末を超える日は月末とする）なら、前月のまま。過ぎていれば当月。所属の課か `close_day` がなければ前月。
- 決め方は `report_target_period()`（`report.php`）にまとめる。設定の `report_period_rule` はまだ読んでいない（共通編 §12）。

## 5. 入力項目と確認

なし。

## 6. 操作と処理

1. 自分の報告（対象月・前月）: `report_records` を `user_id` と `period` で 1 件ずつ探す（`is_legacy = 0 AND deleted_at IS NULL`）。
2. 回答待ち: `report_field_comments` で、自分の報告（削除済みを除く）の `parent_id IS NULL AND thread_status = 'open' AND deleted_at IS NULL`。
3. 臨時の調査: `adhoc_request_targets` で自分が対象、`adhoc_requests.status = 'open'`、`deleted_at IS NULL`、`adhoc_responses.submitted_at` が NULL。
4. 確認者: 自分が `department_reviewers` に入っている課ごとに、対象月の `report_records`（`status IN ('submitted','confirmed')`）と `report_reviews` を突き合わせる。
5. 本文は復号しない（件数と項目名だけを出す）。

## 7. メッセージ

| 状況 | 文言 |
|---|---|
| 所属の課がない | 所属の課が設定されていません。管理者に連絡してください。 |
| すべて済んでいる | いま対応が必要なものはありません。（対象月の報告が提出済みか確認完了で、回答待ち・臨時の調査・確認者の欄がないとき） |

## 8. 記録

なし（中身を出さないため）。

## 9. 検証の観点

- 部下には確認者の欄が出ない。確認者には、自分が確認者の課の件数だけが出る。
- 自分の報告は「未チェック」に数えない。
- 「更新あり」の報告が未チェックに数えられる。
- 削除した報告・コメントが数えられない。
- 対象月が締め日の前後で正しく切り替わる。
- スマートフォンの幅で「今月の報告を作る」がはみ出さない。

自動の検証で試しているのは、表示、回答待ち、臨時の調査、「今月の報告を作る」の表示まで。締め日の切り替えと未チェックの数え方はまだ試していない。
